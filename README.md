# 🚀 AEO & Technical SEO Analyzer

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)

An automated Python tool designed to evaluate website readiness for **Answer Engine Optimization (AEO)** and **Technical SEO** infrastructure. Built by [Linkoster](https://linkoster.com).

## 📌 Features

- ⚙️ **Technical SEO Verification:** Checks status codes, canonical link setups, titles, and meta descriptions.
- 🤖 **AEO Citation Check:** Evaluates `JSON-LD` Schema blocks and identifies concise 40-60 word direct-answer candidate paragraphs.
- 🛡️ **Production-Ready Code:** Includes modular error handling, logging, and custom User-Agent configurations.
